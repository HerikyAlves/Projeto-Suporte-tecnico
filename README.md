
# DeskFlow

O DeskFlow é um sistema de gerenciamento de chamados de TI desenvolvido como projeto de portfólio. A ideia é organizar solicitações de suporte em um só lugar, facilitando o acompanhamento dos chamados e de suas prioridades.

## Sobre o projeto

O projeto surgiu como uma forma de praticar desenvolvimento web e conhecer melhor a construção de uma aplicação com front-end e back-end. Além da interface, estou trabalhando na estrutura de uma API para gerenciar os chamados e armazenar os dados em um banco de dados.

## Funcionalidades

- Cadastro de chamados com título, descrição e prioridade.
- Edição e exclusão de chamados.
- Alteração do status entre aberto e concluído.
- Pesquisa por título ou descrição.
- Filtros por status e prioridade.
- Painel com contadores de chamados.
- API para operações de gerenciamento dos chamados.
